学一门新课，先给它一个 Project。材料、笔记、导图和所有相关会话都放在里面，换学科就换 Project，互不打扰。

建好之后的第一次使用路径很短：把材料放进 Project 的工作目录（或直接在 Files 里新建一篇笔记）→ 从文件树点开它 → 选中一段话 Add Chat，选一个会话，写下你的问题发送。剩下的环节见[读 → 引 → 思 → 图 → 写](/guide/reading-loop/)。

## 三个层级

| 概念 | 是什么 | 例子 |
| --- | --- | --- |
| Workspace | 你的整个工作环境 | — |
| Project | 一门学科或一个主题 | "统计学习" |
| Session | 与 agent 的一次对话线程 | "间隔重复和主动回忆的区别" |

创建 Workspace 时会自动创建一个默认 Project；你也可以新建任意多个 Project。每个 Session 从创建那一刻起就固定属于一个 Project，之后不可更改。

## 创建 Session 的三个入口

- **New Session**：新会话占据 Primary 主面板。
- **New Session in Panel**：在旁边新开一个 Auxiliary 面板放新会话，比如边读 PDF 边问问题。
- **Branch**：从当前会话分叉出子会话，放在来源面板旁边——同一个问题想换条思路问时用。

## 限制与说明

- 默认 Project 不可删除；还留着 Session 的 Project 也不可删除。
- 跨 Project 不通信、不引用、不分支：目标选择列表里看不到其他 Project 的会话，构造请求也会被服务端拒绝。
- 只有未命名、没有消息也没有草稿、且不再显示在任何面板里的空 Session 会被自动清理；有内容或正被使用的会话不会被清掉。
- 删除一个已清空的非默认 Project 时，它的工作台布局和 Browser 一并清理，重启后不会复活。
