学习层的所有功能都是这个闭环中的一环。本页描述的是**设计目标**，目前没有实现；各环节对应的功能见[功能看板](/design/map/)。

## 一次学习：约二十分钟

| 步骤 | 用时 | 发生什么 | 对应功能 |
|---|---|---|---|
| 0. 唤醒 | 2–3 分钟 | 先做到期的复习：闭卷回忆，说把握度，看反馈 | [跨天复习](/design/practice/spaced-review/) |
| 1. 预测 | 1 分钟内 | 对新内容回答一两个直觉问题，不计分，可跳过 | [先猜一下](/design/learn/prediction/) |
| 2. 讲解 | 每段 3–5 分钟 | 引用用户刚才的猜测，给例子，每处都能跳回原文 | [分段讲解](/design/learn/guided-learning/) |
| 3. 说一句 | 每段后约 1 分钟 | "为什么？""如果……会怎样？""用一句话说" | [分段讲解](/design/learn/guided-learning/) |
| 4. 带着帮助练 | 按需 | 遇到困难按阶梯给提示，做得好就撤掉帮助 | [有支架练习](/design/practice/scaffolded-practice/) |
| 5. 交棒 | 按需 | 收起资料，独立讲给 AI 新手听、画出结构、做题或做个小设计 | [闭卷输出](/design/practice/closed-book-output/) |
| 6. 反馈与修正 | 按需 | 先说把握度，再看按量规给出的反馈；修正追加，不覆盖 | [反馈与修正](/design/practice/feedback-repair/) |
| 7. 留下理解 | 1 分钟 | 用一句话写下现在的理解；预测两天后还能不能独立做到 | [我的理解](/design/growth/understanding-versions/) |

## 跨越几天

```text
学习当天     有帮助能做到 / 当场独立做到
   │        （至少隔一夜）
次日以后     第一次延迟回忆，回忆对一次就停
   │        （间隔逐步拉长）
之后几天     复习时把容易混的概念放在一起练，记录预测与实际
   │
迁移        新情境、成对的案例对比、真实任务
```

- **排程**用个人化的遗忘模型（如 FSRS）估计什么时候该复习，而不是固定间隔表。FSRS 主要在闪卡上验证过，用在"重建一个概念模型"这种复杂任务上，参数需要我们自己验证。
- **稳定的延迟证据**要求在不同的日子累计回忆成功三次以上。
- **衰减**：预测回忆概率低于阈值时，显示"需要唤醒"，历史证据保留。

## 能力等级

等级由尝试记录推导，不由 AI 直接宣布。

| 等级 | 名称 | 条件 |
|---|---|---|
| L1 | 正在学习 | 有预测或讲解记录 |
| L2 | 有帮助能做到 | 有成功的尝试，但用到了提示 |
| L3 | 当场独立做到 | 成功、没用提示、闭卷、与原文重合度低于阈值 |
| L4 | 隔天仍能做到 | 满足 L3，跨过至少一夜，并在至少两个不同的日子成功 |
| L5 | 能迁移 | 满足 L3，且是在新情境中做到的 |

## 知识类型决定练习形式

不同类型的知识，有效的学法不同。

| | 事实与术语 | 概念与原理 | 程序与技能 | 判断与设计 |
|---|---|---|---|---|
| 预测 | 猜含义 | 预测现象或结果 | 不先尝试，先看样例 | 先给出自己的方案 |
| 主要练习 | 短答回忆 + 间隔 | 解释、对比、举反例、闭卷画结构 | 样例 → 逐步撤掉 → 独立做题 → 交错 | 对比案例 → 实战 |
| 反馈时机 | 可以延后 | 作答后立即，按量规逐条 | 每一步即时 | 作答后，包含取舍讨论 |
| 主要风险 | 死记硬背 | 讲得流畅但不会用 | 新手过载 | 没有标准答案，难以评估 |

:::caution[待决策]
第一版先支持哪一列，决定了练习和反馈怎么做。这取决于首批用户学什么，目前还没定。
:::

## AI 在每个阶段能做什么

| 阶段 | AI 的角色 | 可以 | 不可以 |
|---|---|---|---|
| 预测 | 提问者 | 给情境、问直觉问题 | 打分、纠正、讲答案 |
| 讲解 | 讲解者 | 分段讲、引用用户的猜测、举例 | 一次讲完一整章 |
| 有支架练习 | 教练 | 按提示阶梯给帮助 | 跳级直接给完整答案 |
| 闭卷输出 | 新手学生，或者沉默 | 以新手身份追问"为什么" | 提示、纠正、补全，或替用户改画布 |
| 反馈 | 评审 | 按量规指出缺了什么，对照原始尝试 | 改写成"标准答案"覆盖用户版本 |
| 复习 | 出题人 | 出变式题，把易混概念放在一起 | 先给看旧答案再问"还记得吗" |

## 待决策的问题

1. 首批用户学什么知识类型（见上表）。
2. 是否采用 FSRS 这类遗忘模型。开源、可以本地运行，但用在复杂理解任务上需要自己验证。
3. 是否允许"找出 AI 草稿里的错误"作为一种练习。有研究支持，但要明确标注，防止用户把故意放进去的错误记成事实。
4. 第一版是否支持口述输出。能大幅降低输出门槛，但转写和评审更复杂。
5. 怎样让 AI 评审可信。量规、依据和申诉是最低要求，是否还需要人工抽检。
