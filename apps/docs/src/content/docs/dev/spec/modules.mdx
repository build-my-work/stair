## 三层结构

```text
学习入口   首页 · 学习 · 练习 · 实战 · 资料 · 成长        ← 用户看到的
              │
学习引擎   学习编排 · 证据模型 · 记忆排程                  ← 没有独立界面
              │
工作台底座 Project · 工作台 · Files · Reader · 引用 ·      ← 已交付
           浏览器 · Drawnix · Agent 会话
```

**依赖只能向下。** 入口可以调用引擎和底座，引擎可以使用底座，底座不知道学习层的存在。这样工作台在没有学习层时仍然完整可用，学习层的改动也不会破坏已有的回归 Case。

## 几条划分规则

- **入口按"用户来做什么"划分，不按"后台有什么能力"划分。** 后台的讲解、出题、可视化、记忆都不单独成为入口。
- **"问 AI"不是入口。** 它是所有入口里都有的上下文动作。AI 知道用户在看什么资料、处于哪个阶段、草稿写到哪了，但回答方式受当前阶段约束。
- **"实战"和 Project 是两回事。** Project 是装材料、会话和布局的容器，属于底座；"实战"是一个学习入口，用户在里面用所学完成真实任务。
- **资料入口不新建存储。** 它是 Project Files、Reader 和浏览器的学习视角，同一份资料只有一个来源。

## 学习层怎样复用底座

| 学习需求 | 复用的底座能力 | 需要新增的部分 |
|---|---|---|
| 闭卷输出 | 工作台的布局挂起与恢复 | 闭卷模式：临时收起资料和浏览器面板，记录这次是否闭卷 |
| 反馈后回到原文 | 引用与跳转 | 每道题都绑定来源位置 |
| 判断是否照抄 | 引用中的原文与文件指纹 | 计算输出与原文的重合度 |
| 闭卷画结构 | Drawnix 与 agent 的画布工具 | 独立输出阶段禁止 AI 写画布 |
| 留下这次理解 | Add Note | 改为用户书写、AI 只提问，并记录作者权 |
| 讲解时并排阅读 | 多面板工作台 | 讲解阶段并排，独立输出阶段切换为单焦点 |
| 学习记录的归属 | Project 与 Session 的归属规则 | 证据数据同样按 Project 隔离 |
