**读到哪，学到哪**：在书里选中一段，直接从这一段开始学。它不是导入资料后自动生成一大堆总结。

你在读书，读到一段关于"滑动窗口"的内容，看了两遍还是似懂非懂。选中它，工具条上除了「问 AI」和「记进笔记」，还多了两个选项：

- **讲讲这段**：从这一段开始，AI 一小段一小段地给你讲。
- **我来说说**：先用一句话写下你觉得这段在讲什么，再对照原文看看。

你选了「我来说说」，写完一对照，发现自己漏了一个关键条件。

## 为什么不一导入就生成总结

很多工具导入一本书，就自动生成总结、导图、闪卡、播客。看起来很丰富，但你多出来的是一堆要读的东西，读完感觉都懂了，其实大多很快就忘。

Stair 把学习放在你正在读的那一段上。

## 你会遇到的

- 一本书只导入一次，笔记、提问、练习都围绕它。
- 选中任意一段，可以「讲讲这段」或「我来说说」，现有的「问 AI」「记进笔记」照旧。
- 你想要总结或者现成的导图时，Stair 会给你，但会标为"参考"。
- 练习题和闪卡会随着你的进度出现，一定是先答、再看答案；答案尽量用你自己写过的话。

## 目前做不到的

AI 生成的总结和导图同样可能有错漏，这也是它们被标为"参考"的原因。

<details>
<summary>给开发：验收约定</summary>

- 导入资料不会自动生成任何消费型产物（总结、播客、现成导图）。
- 消费型产物只在用户主动请求时生成，标为"参考"。
- 检索型产物（问题、闪卡、变式题）按进度生成，用户作答之前不显示答案；答案面优先来自用户的 Attempt 和 Repair。
- 背景见[决策 0003](/dev/spec/decisions/0003-consumable-vs-retrieval/)。

</details>
