**内置浏览器**让网页资料和书并排放。它不是另开一个浏览器，网页上的段落和书里的一样能引用。

很多学习资料在网上：官方文档、技术博客、课程页面。在系统浏览器里看，又回到了来回切窗口、复制粘贴的老问题。

Stair 自带浏览器，网页就开在你的书和笔记旁边。

## 你会遇到的

- **网页开在侧栏里**，和书、笔记、AI 对话并排。
- **网页也能选中引用。** 选中一段，和读书一样可以问 AI、新开对话、记进笔记，出处是网页地址和原文。
- **书签**：常看的页面加个书签，下次直接打开。
- **链接怎么打开你说了算**：对话和笔记里的链接，可以设置成在 Stair 里打开，或者在系统浏览器里打开。
- **切换主题时网页不丢**：切到另一个学习主题再切回来，网页还停在原来的位置。

## 常见问题

**重启 Stair 后网页还在吗？**
目前不会自动恢复，需要重新打开。书签会保留。
