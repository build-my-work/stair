**你的笔记就是普通文件**，存在你电脑上的学习文件夹里。它不是锁在 Stair 里的私有格式，换任何工具都能打开。

学习过程中写下的笔记、草稿、整理稿，是最值得留下的东西。它们不应该被锁在某个应用的私有格式里。

在 Stair 里，你的笔记就是你学习文件夹里的普通文件。

## 你会遇到的

- **看到文件夹里的一切**：右侧栏显示这个学习主题的文件夹，可以搜索、新建文件和文件夹，图片可以直接预览。
- **直接写**：Markdown、文本、代码、配置文件都能在 Stair 里打开和编辑。
- **不用按保存**：停笔不到一秒就自动保存。
- **不会丢稿**：关闭、切换主题、退出 Stair 之前，都会先确认保存好了。万一保存失败，Stair 会拦住你，不会让你带着没保存的内容离开。
- **改冲突了也有办法**：如果文件在别处被改过，你可以选择放弃自己的修改，或者把当前内容另存一份。
- **笔记里的链接能点**：链接到另一个文件会在 Stair 里打开，网页链接按你的偏好打开。

## 常见问题

**不用 Stair 了，笔记还在吗？**
在。它们就是你电脑上的普通文件，用任何编辑器都能打开。

**Stair 会把东西写进我的文件夹吗？**
只有你自己写的笔记和你新建的文件。阅读进度、划线这些记录单独保存，不会塞进你的文件夹。
