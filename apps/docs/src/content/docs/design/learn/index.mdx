**你来这里做什么：把一个新东西弄明白。**

让 AI 讲一遍、看一份总结，当时觉得都懂了，过两天就忘。学习空间想做的，是让你在"听"的过程中一直在动脑。

## 一张表看懂

| 你带着什么来 | 在这里做什么 | 会留下什么 | 下一步 |
|---|---|---|---|
| 一段想弄明白的内容 | 先猜一下，听一小段，说一句 | 你的猜测，和你每次说的那一句 | 觉得懂了，去[练习](/design/practice/) |

## 在学习主线上的位置

```text
  读进来   →  ▶ 想明白   →   讲出来、记得住   →   用得上
```

## 一次学习是这样推进的

1. **先猜一下**：开讲前，凭直觉回答一个小问题。
2. **听一小段**：AI 基于你的资料讲几分钟，接着你的猜测讲。
3. **说一句**：每段讲完，用一句话说说"为什么"。
4. 重复 2–3，直到这一节讲完。

整个过程中，AI 是讲解者：它讲，但也会停下来等你。
