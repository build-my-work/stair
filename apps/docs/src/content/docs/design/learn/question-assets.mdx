这是一个**还在构思**的想法：把你问过的问题当成学习的一部分留下来。

读第 3 章时，你问过 AI 一个问题："为什么 TCP 不直接用网速测试来决定发多快？"当时没完全弄明白，就接着往下读了。

两周后学到第 6 章，这个问题突然有了答案。如果 Stair 能在这时提醒你："还记得你在第 3 章问过的那个问题吗？"——那一刻会特别通透。

## 我们在想什么

一个问题里藏着很多东西：你在关注什么，知道到哪了，卡在哪，真正想弄明白的是什么。可现在的聊天把问题当成换答案的一次性消息，答完就被翻过去了。

我们想把你的问题当成学习的一部分留下来：

- 记住它是在读哪一段、学到哪一步时冒出来的；
- 记住它后来怎么样了：被解答了、自己想通了、引出了新问题，还是一直悬着；
- 还没解决的问题，可以成为后面讲解和复习的切入点。

## 还在想的问题
