这是一个**还在构思**的想法：开始学一个新主题前，先用一句话写下你学它是为了什么。它不是填表，也不会被打分。

你新建了一个"TCP"的学习主题。开始读之前，Stair 问你：

> 你学这个是为了什么？想用它解决什么事？

你写下："视频会议总卡，想知道问题出在网络的哪一环。"

几天后，讲到拥塞控制时，AI 会顺带提一句："这正好能解释你视频会议卡顿的一种原因。"学完之后，[实战](/design/apply/)里第一件事，就是拿它去排查那次卡顿。

## 为什么要先想这一句

带着一件自己在乎的事去学，你会更愿意学下去，也更容易记住，因为每个知识点都有了挂的地方。很多人学到一半放弃，不是因为太难，而是忘了自己为什么开始。

## 怎样算一句好的"为什么"

| 不太好用 | 更好用 |
|---|---|
| 学一下 TCP | 搞清楚视频会议为什么会卡 |
| 提高编程能力 | 能自己看懂公司服务的网络超时日志 |
| 准备面试 | 能讲清楚 TCP 为什么要三次握手，并回答追问 |

好的那一句，通常是一件**具体的、做到了你自己能知道**的事。
