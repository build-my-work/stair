**先猜一下**是开讲前的一两个小问题，一分钟内就能答完。它不是摸底考试：不打分，猜错也有用。

你打开 TCP 那本书，准备学"拥塞控制"。Stair 没有直接开讲，而是先问你：

> 网络突然变慢时，你觉得发送方应该怎么做？

你想了几秒，写下："大概是先停一下，等会儿再发？"

然后讲解开始了：

> 你说"先停一下"，方向是对的。不过 TCP 不是停下来，而是把发送速度直接砍掉一半，再慢慢加回去……

## 为什么要先猜

带着一个猜测去听，你会不自觉地留意"我猜得对不对"。讲解就不再是从耳边滑过去的一段话，而是在回答你自己的问题。

而且，**猜错的地方往往记得最牢。** "原来不是这样"的那一下，比直接被告诉答案深刻得多。

## 你会遇到的

- 每次开始一个新主题，Stair 会问你一到两个问题，一分钟以内就能答完。
- 随手写一句就行，不用写完整，也不用查资料。
- 不打分，不算成绩，只有你自己能看到。
- 不想猜？点「跳过」，直接开讲。
- 讲解会接着你的猜测往下讲，告诉你猜对了哪部分、漏了哪部分。

## 什么时候不会问你

如果你在学一项操作性的技能，比如第一次写某种算法，Stair 会先给你看一个完整的例子，而不是让你凭空猜。这种时候硬猜只会让人挫败。

## 和摸底测试有什么不同

摸底测试是为了判断你会不会、决定你该学什么，所以要计分。先猜一下只是让你在听讲前先动一下脑：不计分，不分级，也不影响你接下来学什么。在还没学的时候，猜错才是正常的。

## 目前做不到的

问题出得好不好，取决于资料和 AI。如果某个问题让你完全无从下手，直接跳过就好。

## 常见问题

**这是摸底考试吗？**
不是。你的回答不会被用来给你分级，也不会决定你"该学什么"。它只是让你在听讲之前先动一下脑。

**我老是猜错，是不是说明我不适合学这个？**
完全不是。在你还没学的时候，猜错才是正常的。猜错之后再学，效果往往比没猜过更好。

**能关掉吗？**
每次都可以跳过。如果你经常跳过，Stair 会把问题出得更简单、更贴近生活。
