## 一条主线

Stair 只帮你做一件事：**把一样东西真正学会。** 这件事分成四段：

```text
  读进来   →   想明白   →   讲出来、记得住   →   用得上
```

只读进来，是看过；想明白了，是懂了；合上书能讲出来、隔几天还记得，才是会了；在新的问题里用得上，才是真的变成了你的。

很多学习工具只帮你做第一段，或者用 AI 替你做完第二段。Stair 想陪你走完全程。

## 六个空间

主线上的每一段，在 Stair 里都有一个对应的地方。你在 Stair 里走动，就是在这几个空间之间走动：

```text
                    ┌──────────── 首页：每次从这里接着学 ────────────┐
                    │                                              │
  主线      读进来    →    想明白    →   讲出来、记得住   →   用得上
  空间       资料           学习             练习              实战
                    │                                              │
                    └──────────── 成长：看见每一步的进步 ────────────┘

  底座     工作台与 AI：按主题分开的学习空间 · 并排的屏幕 · 你的笔记文件 · 身边的 AI
```

- **首页**和**成长**不属于某一段，而是在两头：首页帮你开始，成长帮你回头看。
- **工作台与 AI**是所有空间共用的底座。不管在哪个空间，书、笔记和 AI 都在同一个屏幕上。

## 现在走到哪了

底座和「资料」已经能用了：你可以在 Stair 里读书、看网页、选中就问 AI、记笔记、画导图。

「学习」「练习」「实战」「成长」和「首页」还在路上，它们会让 Stair 从一个好用的学习工作台，变成一个帮你真正学会的地方。
