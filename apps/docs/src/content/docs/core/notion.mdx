Project 可以选择以 Notion 保存笔记和文档。在 Project Settings 的「项目文档」中选择 Notion，设置连接和父页面。不同 Project 可以绑定同一个连接下的不同父页面。

## 配置连接

在 Sources 中点击「＋ → Notion」，填写 API Token 后点击「连接」。Stair 内置了 API 地址、Bearer 认证和连接测试；验证通过后才创建 Source，并将 token 保存到加密凭据存储中。无需填写 URL 或运行配置助手。个人使用可以采用有 Notion API 权限的 PAT；内部集成 token 需要先在 Notion 中获得父页面的访问权限。

接着进入 Projects → 选择项目 → Settings，将「项目文档」设为 Notion，选择刚创建的连接，填写父页面链接并保存。同一工作区的不同 Project 可以复用连接，各自绑定不同父页面。其他类型的数据源仍通过「＋ → 自定义数据源」配置。

Project 配置只保存连接 slug 和父页面 ID，不保存 token。网页需要另外登录；MCP OAuth token、网页 cookie 和 REST token 不能互换。

## 浏览与编辑

绑定后，右侧显示父页面下的页面树。展开一层时加载对应的子页面，包括分栏、折叠块里的子页面。数据库显示入口，点击后交给 Notion 原网页处理。

点击页面会在主工作台打开 Notion 原网页，每个 Project 在一个工作台窗口内复用一个面板，可以与聊天并排。切换 Project 会隐藏并保留页面，回来后继续编辑。保存由 Notion 自己负责；关闭或离开时，如果网页阻止离开，Stair 尊重它的提示。网络离线时应先确认 Notion 的保存状态。

Notion 面板默认宽度为 760px；并排时按设定宽度显示，多余空间由相邻面板填充，单独显示时铺满工作区。可拖动边界调整宽度，双击右侧分隔线恢复默认宽度；已有的手动宽度继续保留。

网页保留 Notion 自己的导航栏；外壳沿用工作台的焦点、阴影和圆角规则。多个面板并排时，小横杠直接悬浮在网页上沿，不保留常驻横条或占用正文高度；鼠标悬停在横杠上会展开与其他面板标题栏同高的浮动拖动区。可在其上用触控板左右滑动或按住鼠标拖动，横向查看聊天与 Notion；拖动期间保持展开，移开后收起，网页尺寸保持不变。聚焦拖动区后也可使用左右方向键。聚焦网页后按 Cmd/Ctrl+W 可关闭面板。网页明暗跟随 Stair 的实际主题，切换主题不刷新网页。

网页使用独立、受限的持久浏览会话，不接入普通 Browser 的 CDP 工具。网页登录只支持邮箱验证码，请使用能访问父页面的 Notion 账号邮箱；不支持 Google 等第三方登录。工作台中的 Notion 只支持 Stair Desktop。

## Agent 读写

- `project_notion_read` 读取当前页；`children: true` 列出子页面，不指定页面时从父页面开始。
- `project_notion_open` 在工作台打开指定的已有页面；没有面板但 Project 已在窗口中打开时，会先创建面板。
- `project_notion_write` 只写当前打开的页面，默认追加；提供 `oldText` 时进行精确、唯一匹配的修改。写入遵守当前会话的权限模式。

需要保存笔记或产物时，Agent 先读取当前页。如果没有打开页面，先定位并打开目标；目标不明确时询问用户。不会自动选择父页面，也没有默认笔记页或产物页配置。需要新页面时，在 Notion 原网页中创建后打开它。

Agent 操作限于当前会话所属 Project 的父页面范围。读完后切页、更换连接或关闭宿主窗口时，旧写入会失败，要求重新读取；已发出的请求固定写原来的页面。多个窗口无法唯一定位时不猜测。写入结果不明时先读取核实，不自动重复追加。

网页显示出与地址匹配的完整页面后，Agent 才能将它作为当前写入目标。登录界面、加载占位和仍在切换中的页面都不会取得写入目标。

Stair 不强制刷新正在编辑的网页，API 更新是否立即出现在原网页中由 Notion 自身同步决定。首版不包含数据库记录的 Agent 编辑、多个 Notion 面板并排、本地同步或选区引用。
