零散的笔记缺一张图把它们挂起来。Drawnix 白板以 `.drawnix` 文件的形式活在 Project Files 里——它就是普通文件，享受同样的自动保存、冲突保护和重启恢复。

<Screenshot name="drawnix-board" caption="章节导图：把笔记和 agent 的回答挂到结构上" />

## 日常操作

- **创建**：在 Project Files 里新建 `.drawnix` 文件；单击进入 Preview 画板，右键 Open in New Panel 可以长期并排。
- **编辑**：Pointer 或键盘都行。停止编辑 800 毫秒自动保存；关闭面板、切换 Project 前先落盘。
- **让 agent 参与**：对当前会话说"把这几条挂到第二章下面"，agent 通过 mindmap 工具直接改画板——细节见 [Agent 工具](/core/agent-tools/)。

## 保存语义

白板复用 Project Files 的整套保存机制：文件指纹比较、写盘失败重试、关闭前 flush、冲突不覆盖。区别只有上限——白板文档允许到 8 MiB（普通文本仍是 1 MiB）。

## 限制与说明

- agent 更新以批次为单位，单批最多 50 个操作；批内失败整体回滚，画板上不会留下做了一半的修改。
- 用户手动编辑、agent 更新、演示状态保存三条线互不覆盖：agent 改导图的同时你继续打字是安全的。
