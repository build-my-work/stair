# ThetaWave 产品参考档案

> 审计日期：2026-09-02<br>
> 官方网站：<https://thetawave.ai/zh><br>
> 用户提供入口：<https://thetawave.ai/zh/app/dashboard><br>
> 证据范围：本次只核验无需登录即可访问的官方功能页；登录态 Dashboard 的实际交互、生成质量和状态持久化未重新实测。

## 一句话定位

ThetaWave 是一个以“同一份来源”为中心的 AI 学习资料工作区：把 PDF、课堂录音、YouTube、网页和文本转成结构化笔记，再在同一上下文中切换总结、闪卡、测验、思维导图、播客和 AI Tutor。[官方功能总览](https://thetawave.ai/zh/feature) [AI Study Assistant](https://thetawave.ai/feature/ai-study-assistant)

## 已验证的产品事实

### 1. 一个来源，多种学习表面

官方流程是“上传一次，在多个学习模式间切换”：来源被索引为一个 Study Session，Original、AI Notes、Summary、Flashcards 与 Quizzes 共用同一底层材料，侧边 AI Tutor 也围绕同一来源回答问题。[官方工作流](https://thetawave.ai/feature/ai-study-assistant#how-the-ai-study-assistant-works)

同一来源还可以派生思维导图、信息图和播客，不需要反复重新提示；官方明确把 Chat、Notes、Mind Map、Quizzes、Flashcards 和 Podcast 绑定在同一来源上下文中。[官方能力说明](https://thetawave.ai/feature/ai-study-assistant#why-thetawave-as-your-ai-study-assistant)

### 2. 先声明学习目的，再组织输出

用户上传时可以说明目的，例如备考、测验复习、作业或理解课程；官网称生成结果会按目的调整。[学习助手](https://thetawave.ai/feature/ai-study-assistant#why-thetawave-as-your-ai-study-assistant) [笔记生成器](https://thetawave.ai/zh/feature/notes-generator#为什么用-ai-笔记生成器)

### 3. 输入兼容与来源连续性

公开页面列出的输入包括 PDF、DOCX、PPTX、TXT、Markdown、音视频、图片、YouTube、网页和粘贴文本。生成笔记保留来源上下文，并可继续派生闪卡、测验、信息图或播客；笔记可以按课程和文件夹管理、搜索与导出。[笔记生成器](https://thetawave.ai/zh/feature/notes-generator)

### 4. 练习形式明确、进入成本低

测验支持单选、判断、填空和简答，并提供 3、5、10 分钟三种练习深度、即时解析、范围聚焦和测验历史。官方流程是“导入范围 → AI 出题 → 用户作答并发现盲区”。[测验生成器](https://thetawave.ai/zh/feature/quiz-maker)

闪卡面向术语、公式、定义与事实的主动回忆；思维导图自动识别主概念、子概念和层级关系，允许展开、折叠、缩放和导出。[闪卡生成器](https://thetawave.ai/zh/feature/flashcard-maker) [思维导图生成器](https://thetawave.ai/zh/feature/mind-map-maker)

## 产品判断

### 最强之处：来源连续，而不是单个生成器

ThetaWave 最值得借鉴的不是“能生成很多东西”，而是**所有学习表面共享同一个来源对象和上下文**。用户不需要在笔记、聊天、闪卡和测验之间重复导入、复制或解释背景。

它解决的是学习工具常见的碎片化：输入、整理、提问、练习和回顾虽然仍是不同模式，但不会变成互不相认的文件和会话。

### 主要风险：Artifact Factory

ThetaWave 的默认价值叙事仍然偏向“上传一份资料，立即得到更多学习产物”。这些产物可以降低整理成本，却不能自动证明用户完成了理解、独立输出、延迟回忆或迁移。

如果 Stair 原样照搬“一个来源生成六种产物”，会进一步放大用户已经存在的 Input 过多问题：收藏的不再只是文章，而是一整套 AI 笔记、导图、播客、闪卡和测验。

本次公开页面审计没有找到以下可确认机制：

- 用户第一次独立输出及原稿保存；
- AI 支架使用记录；
- 修正前后的认知差异；
- 延迟后无辅助重建；
- 从练习迁移到真实项目的行为证据。

这只是对公开页面证据边界的说明，不代表登录产品中一定不存在。

## Stair 应该吸收什么

1. **单一来源，多种用途**：一份资料只导入一次，学习、练习、项目、问 AI 都引用同一个来源和定位信息。
2. **上下文不丢失**：用户从笔记切到问 AI、再切到练习时，主题、来源和当前位置保持连续。
3. **显式学习目的**：生成教学和练习前知道用户要“理解、备考、解决项目问题还是快速复盘”。
4. **低门槛练习入口**：3 分钟、5 分钟、10 分钟是自然选择，比题量和复杂配置更容易理解。
5. **整体与局部切换**：正文用于细节，关系视图用于整体，但视觉结构只作为理解支架，不作为用户已经掌握的证据。
6. **格式是视图，不是新对象**：笔记、导图、问答和练习应围绕同一 Learning Item / Source 派生，避免复制出多个失联文件。

## 不应该照搬什么

- 不默认把所有来源都批量生成全部产物。
- 不把“生成了笔记、闪卡、导图”显示成学习进度。
- 不让播客和总结成为逃避主动回忆的新输入渠道。
- 不因为测验由资料生成，就默认题目可靠或足以覆盖迁移能力。
- 不把文件夹、格式选择和 Artifact 管理变成首页主任务。

## 映射到 Stair 六个入口

| Stair 入口 | 借鉴方式 |
|---|---|
| 首页 | “继续上次”恢复到同一来源、同一学习阶段和草稿，而不是进入生成物 Dashboard |
| 学习 | 同一来源下提供教学、示例和整体结构视图；先 Learn，再交棒给用户 |
| 练习 | 从当前来源和能力目标生成短练习，记录原始 Attempt、帮助与修正，而不只保留分数 |
| 项目 | 资料和“我的理解”可以带入真实任务；项目结果反过来成为迁移证据 |
| 资料 | 继承其多格式输入和来源连续性，但只保留一个 Source 对象，不复制六套内容 |
| 成长 | 不统计生成物数量；展示独立完成、延迟重建和新情境应用的证据 |

## 对最终产品的贡献

ThetaWave 应贡献的是 **Source-centered Workspace**：

```text
一个来源
├── 用它学习
├── 用它练习
├── 用它支持项目
├── 围绕它问 AI
└── 查看由它产生的“我的理解”和能力证据
```

Stair 需要在其上增加 ThetaWave 公开流程中不突出的部分：学习阶段状态、交棒、用户独立输出、认知差异、延迟复习和迁移证据。

## 验证边界

- 已验证：官方公开功能矩阵、来源类型、学习模式、测验选项、思维导图能力、目标驱动生成和导出说明。
- 未验证：登录后 Dashboard 的真实导航层级、移动端一致性、生成质量、题目准确性、保存恢复细节、是否存在隐藏的间隔复习算法。
- 官网中的效率、用户数量和学习效果数字属于厂商陈述，本档案不把它们当作已独立验证的产品成效。
