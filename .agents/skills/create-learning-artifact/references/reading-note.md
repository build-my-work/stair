# Reading-note template

Use the sections that improve the result; omit empty sections.

```markdown
# <Specific topic>

## Core idea
<A short synthesis in the writer's own words.>

## How it works
<Mechanism, sequence, or causal relationships.>

## Key distinctions
- **A vs. B:** <why the distinction matters>

## Example
<A concrete example derived from, but not falsely attributed to, the source.>

## Review prompts
1. <Question that tests understanding rather than recall alone>

## Sources
- `<project-relative path>` — <chapter/page/selection when known>
```

Set `templateId` to `reading-note`.
