# Q&A-note template

Group related questions and make each answer independently useful.

```markdown
# <Topic>: Questions and Answers

## Q1. <Precise question>

**Answer:** <Direct answer first.>

**Why:** <Reasoning or mechanism.>

**Common confusion:** <A nearby misconception, only when useful.>

## Follow-up checks
- <A short transfer question>

## Sources
- `<project-relative path>` — <chapter/page/selection when known>
```

Set `templateId` to `qa-note`.
